# 2026年度募集馬 厩舎評価マスタ

## 概要
2026年度募集馬を預託する主要厩舎のうち、一口馬主クラブ(サンデー・社台・シルク・キャロット・ノルマンディー等)所属の著名馬を管理する20厩舎を対象に、WebSearchで確認できた一次情報に基づき評価した。

## 重要な制約・注意事項(必読)
- 本セッションの環境ポリシー上、WebFetch(ページ本文の直接取得)が使用不可(403エラー)だったため、**WebSearchの検索スニペットのみ**を情報源としている。各クラブ公式サイトの募集馬一覧表(厩舎欄)や一口馬主DB(umadb.com)の詳細分析ページ本文は直接確認できていない。
- そのため「クラブ馬勝ち上がり率」「OP到達率」「募集価格回収率」「クラブ別預託頭数」など統計データの多くが「情報不足」となっている。スコアはWeb検索で実際に確認できた事実(GI/重賞実績、JRA公式記録、リーディング順位、調教師本人のコメント等)に基づく絶対評価であり、厩舎の知名度だけで加点していない。そのため、実績十分でも直近データの検索ヒットが少ない厩舎(藤原英昭・堀宣行等)はスコアが実力に対して保守的になっている可能性がある。
- 対象は当初依頼の「50〜80厩舎規模」から、ユーザー合意のもと「WebSearchのみで確認できる著名厩舎20件」に規模を縮小して実施した。
- 一部の厩舎(大久保龍志・昆貢)は所属クラブ名が検索で確認できず、クラブ馬向き適性を保守的に評価している。

## ファイル構成
- trainers.csv: 厩舎マスタ(総合スコア・カテゴリ別スコア・ランク・タグ・サマリー)
- trainer_scores.csv: カテゴリ別採点根拠(5カテゴリ×20厩舎=100行)
- trainer_tags.csv: 厩舎ごとのタグ(正規化)
- trainer_blood.csv: 種牡馬相性評価
- trainer_comments.csv: 強み・弱み・向く血統・向かない血統・総評コメント

すべてUTF-8で出力。
